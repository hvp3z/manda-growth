# campaigns — Une campagne = un dossier (append-only)

Structure : `campaigns/<slug>/` contenant `brief.md` (objectif, cible, angle, guardrails vérifiés) · les assets livrés ·
`results.md` (métriques réelles : impressions, clics, inscrits, réponses — datées).

- Append-only : on n'écrase jamais le dossier d'une autre campagne (même discipline que `md-map/tasks/CP-XX/`).
- Le vendredi, `growth-marketer` compile `campaigns/WEEKLY.md` : métriques vs GOALS, ce qui a marché, signaux émis.
- Les enseignements durables (angle qui convertit, format qui flop) → `memory/learnings/`, un fichier par enseignement.

Campagne existante côté produit (référence, ne pas dupliquer) : visuels minéraux v1.1 dans
`agent-md-framwork/content-factory/output/mineral-v1/` (20 visuels QA-validés + captions.md + calendar.md).
